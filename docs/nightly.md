# Firefox Nightly

FF Ultima supports Firefox Nightly through the `ultima.enable.nightly.config` setting. This allows you to use the same version of the theme as everyone else. It also allows me to separate/manage upstream code all in one place. Whenever new changes finally reach Default Firefox and Developer Edition, they can be rotated out of the `ultima.enable.nightly.config` setting, and into their related source file.

If you use Firefox Nightly, then you're already aware that a new update can pop up almost every other day. The themes source can also recieve updates pretty often (regardless of release version). I personally do not use Nightly, but do make time to respond/fix bugs when I discover them. And honestly, I only ever discover them when you inform me about them via `Issues`, so if you notice anything off ->

- 🗨️ [Submit an issue](https://github.com/soulhotel/FF-ULTIMA/issues/new/choose) if you ever discover a new bug.
