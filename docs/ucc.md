# userChrome Companion

 userChrome Companion is a Firefox extension built to bridge the gap between userChrome & custom -moz-preferences (about:config). In short, it lets you toggle/manage/organize preset list of preferences. UCC was originally created to provide a more smooth & comfortable experience for FF Ultima users. But it is not exclusive to one theme.

- Any theme that utilizes -moz-pref's (user.js), can be used with this extension.
- Any theme that utilizes the about:config page to toggle settings, can be used with this extension.
- Any moz-pref (custom or native to Firefox) (like legacyUserProfileCustomizations.stylesheets) can be toggled with this extension.
